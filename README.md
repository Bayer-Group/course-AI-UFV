# AI in Plant Breeding: Fundamentals and Applications

**FIT 796** · Department of Agronomy (DAA) · Universidade Federal de Viçosa

In-person intensive course, **November 3–5, 2026**, at the Department of Agronomy Auditorium.

A partnership between UFV, Bayer, and Instituto IDATA. The course combines academic excellence, technological innovation, and data to prepare professionals for plant breeding.

This repository holds the schedule for this edition and the materials for each module.

## Who is it for

- Graduate students
- Researchers
- Plant breeders
- Data scientists
- Seed industry professionals
- Agribusiness specialists

## The course

The academic program registers FIT 796 with 3 credits and 45 total hours: 3 lecture hours per week, no lab hours, over 15 weeks, in term II. There are no prerequisites.

The syllabus, in the order of the academic program, covers:

1. Introduction to Artificial Intelligence
2. High-throughput phenotyping with AI support
3. Artificial Intelligence and data
4. Hands-on implementation and AI-assisted coding
5. Genomic selection with AI support
6. Machine learning and deep learning in plant breeding
7. Generative AI and language models in scientific research
8. Decision-making in breeding programs
9. Optimization and simulation
10. Future trends, Q&A, and closing

The intensive edition also includes the module [AI concepts, models, agents, IDEs, and hardware for AI](02.%20Conceitos%20em%20IA%2C%20Modelos%2C%20Agents%2C%20IDE%2C%20Hardware%20para%20IA_Kaique). On November 4, optimization and simulation ([Éder](08.%20Otimiza%C3%A7%C3%A3o%20e%20Simula%C3%A7%C3%A3o_Eder), [Vitor](09.%20Otimiza%C3%A7%C3%A3o%20e%20Simula%C3%A7%C3%A3o_Vitor)) shares the afternoon with generative AI ([Éder](10.%20IA%20Generativa%20e%20Modelos%20de%20Linguagem%20na%20Pesquisa%20Cient%C3%ADfica_Eder), [Kaique](11.%20IA%20Generativa%20e%20Modelos%20de%20Linguagem%20na%20Pesquisa%20Cient%C3%ADfica_Kaique)). Decision-making is on the morning of November 5, before the discussion on models and tools and the closing session.

## How to download this repository

### Option 1 — Git (recommended)

```bash
git clone https://github.com/bayer-int/course-AI-UFV.git
cd course-AI-UFV
```

### Option 2 — ZIP download (no Git required)

1. Go to the repository page on GitHub.
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Extract the ZIP file to a folder of your choice.

### Option 3 — GitHub CLI

```bash
gh repo clone bayer-int/course-AI-UFV
cd course-AI-UFV
```

> **Note:** This is a private Bayer repository. You need access to the `bayer-int` GitHub organization to clone or download it.
