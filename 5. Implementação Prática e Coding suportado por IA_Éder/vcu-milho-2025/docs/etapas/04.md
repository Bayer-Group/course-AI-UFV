# Etapa 04 -- Analise individual e conjunta

## O que foi feito
Analise por ambiente (PROD ~ bloco + (1|genotipo)) e analise conjunta
(PROD ~ ambiente + (1|ambiente:bloco) + (1|genotipo) + (1|genotipo:ambiente)).
Ranking das 400 linhagens DH25 por BLUP do modelo conjunto.

## Como reproduzir
```bash
Rscript R/01_importar.R
Rscript R/02_qc.R
Rscript R/03_curar.R
Rscript R/04_analise.R
Rscript tests/04_test_analise.R
```
