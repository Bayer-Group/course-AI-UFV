# Etapa 03

## O que foi feito

Curação de `data/intermediario/01_importado.rds` em três passos, na ordem:
1. Normalização de `germoplasma_nome` (`toupper + trimws`).
2. IDs que ainda falham na regex após normalização registrados como `id_fora_padrao_pendente`.
3. Duplicatas de posição (chave: `ensaio_id:linha:coluna`) removidas; primeira ocorrência lexicográfica mantida.
4. `PROD` fora de [2000, 20000] convertido para `NA`.

Todas as alterações registradas em `docs/registro_de_correcoes.csv`. Script é idempotente
(15 linhas no registro antes e depois de duas execuções consecutivas).

## Como reproduzir

```bash
Rscript R/03_curar.R
Rscript tests/03_test_curar.R
```

## Decisões

- IDs com erro de separador (`DH25 0138`, `DH25-0287`) não são corrigidos
  automaticamente por falta de evidência; ficam no curado e no registro como
  `id_fora_padrao_pendente`. Ver `docs/decisoes.md`.
- Deduplicação do registro usa `unique(rbind(...))` para garantir idempotência;
  chave efetiva é o conjunto de todas as colunas incluindo `data`. Ver `docs/decisoes.md`.
